# DSH 智能路由

为 DeepSeek Harness 增加一个**独立的「智能路由」模型**，以及「设置 → 智能路由」配置页。基于 [LYiHub/pub-dsh-privacy-router](https://github.com/LYiHub/pub-dsh-privacy-router) 改造。

- 选择 **智能路由**：按设置使用「智能路由」或「私密开发协作」模式。
- **私密开发协作**：在线模型负责公开架构与代码，本地模型处理私密实现；两者使用独立的项目视图和会话记录。
- 选择 **Qwen 或其他普通模型**：直接使用所选模型，插件不会分类、改道或阻止其请求。
- 设置页可更换路由的本地与云端目标，修改隐私判断规则、敏感词及检测选项；保存后从下一轮生效。

## 使用

在已安装 DSH 的机器上安装本 fork：

```sh
dsh plugin --profile web add github:Leon-Geldmann/pub-dsh-privacy-router
dsh web
```

打开 **设置 → 智能路由**，选择本地模型、云端模型和工作模式并保存。然后在聊天的模型菜单中选择 **智能路由**。从旧版升级时需重启 DSH；原有安装默认保留智能路由模式。

模型的内部标识是 `privacy-router / auto`。实际处理模型由路由决定，聊天的选择仍保持「智能路由」；可以随时切回普通模型。

如果是从上游的全局路由版本升级，替换插件后在 profile patch 中补充本地目标，并重启 DSH。无需修改 DSH 核心源码。

## 私密开发协作

适合在线模型设计整体架构、实现公共模块，本地模型开发敏感模块的场景。插件管理两个有步数上限的模型工作循环，提供文件读取、写入、命令执行和本地任务委托。在线模型只接触获准公开的材料。

在设置页选择 **私密开发协作**，填写：

| 设置 | 示例与含义 |
| --- | --- |
| 项目根目录 | 本机项目的绝对路径，例如 `/path/to/project` |
| 公开路径 | 每行一个相对路径；`public/` 授权目录，`public/api.js` 授权单个文件 |
| 私密路径 | 如 `private/`、`tests/`；与公开路径重叠时私密优先 |
| 公开项目简介 | 可发送给在线模型的目标、架构、接口和约束 |
| 集成测试命令 | 如 `node --test public/*.test.js tests/*.test.js`，仅在本地隔离环境执行 |
| 最大工作步数 / 命令超时 | 限制每个模型循环和单次命令的工作量 |

路径不支持通配符、绝对路径或 `..`。未获准公开的文件默认私密。把目录设为公开，就是授权发送其中符合规则的文件内容；不要把私密实现放进公开目录。

**普通聊天消息默认留在本地。** 新的公开需求使用 `/公开 ` 前缀，例如：

```text
/公开 请为公开模块设计缓存接口，私密数据的读取实现交给本地模型。
```

该标记只授权这一条直接发送的消息，不包含以前的聊天或同时排队的其他消息。保存的公开项目简介也会发送给在线模型。插件不会把本地模型生成的摘要自动视为可公开材料。

在线模型依据公开简介、获准公开的当前消息和自己的公开历史工作，可以委托本地模型实现内部接口。本地模型能读取公开接口、私密文件和未公开指令，但不能通过修改公开文件把私密内容发布出去。在线模型不会收到 DSH 外层会话历史、项目系统提示词或继承的工具。

本地任务和集成测试向在线模型返回固定回执；**回执不代表成功**，也不包含成功状态、私密路径、日志或代码。完整结果只显示在本地会话中。若私密错误需要调整公开接口，由你明确提供可公开的接口修改要求。

### 项目与命令隔离

Linux 命令执行使用 `bubblewrap`（`bwrap`）；0.4.0 的 macOS 后端使用本机 Docker／Colima 引擎和 Python 3 文件助手。Mac 的容器运行 Linux 命令，不能直接调用原生 macOS SDK。完整部署与目标机器验收见 [Mac mini 安装说明](docs/mac-mini.md)。文件操作使用独立快照，命令只能访问对应快照和只读的系统运行环境，不能访问主机家目录、凭证、环境变量或网络。隔离不可用时会报错，不会降级到直接运行。

`.env*`、常见密钥/凭证文件、版本库元数据及 `node_modules`、构建产物、依赖缓存等不会进入任一项目快照。适合使用 Linux 系统运行时或预备好的本机容器镜像进行离线开发与测试；依赖联网下载、主机缓存或外部服务的命令不能直接执行。

写回前会检查原文件是否被外部修改；发生冲突则停止相应提交。每个已完成阶段可以独立写回，因此后续中断不会撤销此前已完成的阶段。中断请求不会自动重复修改；用新消息继续。

公开与私密历史分开持久保存，保留量有上限，旧的完整轮次会被清理。修改项目授权、公开简介或模型目标会启用新的历史范围；进行中的协作也会在后续调用或写入前重新检查授权。

## 智能路由模式的规则

默认使用隐私优先策略：

1. 凭证、私钥等确定性敏感内容留在本地。
2. 邮箱、电话号码和本地路径默认留在本地，这三类检查可在设置页调整。
3. 自定义敏感词命中时留在本地。
4. 其余内容交给所选本地模型，结合最近会话判断；只有安全且可独立回答的公开文本才发送到云端。
5. 分类失败、不确定、依赖不能公开的上文、非纯文本输入和超过检查限制的输入均留在本地。

云端只收到通过检查的本轮用户文本、固定系统提示词和空工具列表。不会收到项目系统提示词、历史本地会话、文件内容或本地工具定义；云端回复提出工具调用时会被拒绝。

工具续步和重试复用本轮判断。进行中的一轮不会因设置变化而临时更换目标或规则。没有完整主会话检查上下文的辅助请求保守地使用本地目标。

## 设置页

| 设置 | 作用 |
| --- | --- |
| 本地模型 | 路由模式执行分类与本地回答；协作模式实现私密任务 |
| 云端模型 | 处理获准公开的请求或公开开发任务 |
| 隐私判断规则 | 路由模式的本地分类规则；协作模式以明确授权为准 |
| 敏感词 | 每行一个，不区分大小写 |
| 邮箱 / 电话 / 本地路径检查 | 路由模式的检查；不覆盖协作模式的明确共享授权 |
| 高级选项 | 检查内容字节限制、分类输出上限和云端输出上限 |

配置由 DSH 的 `privacy-router` 设置命名空间持久保存。保存失败会保留编辑内容；旧页面覆盖较新配置时会提示冲突，需要重新加载。

## 推理等级

在聊天的模型菜单中，智能路由提供 **默认、关闭、低、中、高** 五个选项。隐私分类固定关闭推理，不受回答等级影响。

| 统一选择 | Qwen | DeepSeek |
| --- | --- | --- |
| 默认 | medium | high |
| 关闭 | off | off |
| 低 | low | low |
| 中 | medium | high |
| 高 | high | max |

**默认跟随本地模型声明的默认档位**，本地未声明时按中档处理。上表默认对应 Qwen Medium；本地默认为 Low 时，云端也使用 Low。本地默认为 High 时，云端使用 Max。云端自己的默认值不覆盖这项对应关系。

低 / 中 / 高按模型支持的推理档位从低到高对应，不按同名匹配。其他模型使用最低、中间（偶数档取较低者）、最高可用推理档；只有开关时正向等级映射为开启。不提供推理控制的模型不发送推理参数。选择关闭时，不能关闭推理的模型会明确报错；无法识别档位含义时提示直接选择该模型。

各模型对应档位不代表完全相同的思考量。直接选择普通模型仍使用该模型自己的推理菜单，不经过上述映射。

## 信任本地模型

本地目标必须属于主机配置的信任名单。默认信任 `local-ai-` 前缀，便于配合已有的本地发现 Provider。使用其他 Provider 时，在 `$DSH_HOME/profiles/web/cordis.patch.yml` 配置：

```yaml
- id: privacy-router
  config:
    localProvider: my-local-ollama
    localModel: qwen3
    cloudProvider: deepseek-official
    cloudModel: deepseek-flash
    trustedProviders:
      - my-local-ollama
    trustedProviderPrefixes: []
```

名单属于主机配置，设置页不会修改它。请核实所信任 Provider 的 endpoint 确实位于本机或你信任的本地环境；Provider 名称本身不能证明这一点。模型密钥仍由 DSH 原有的模型设置管理，插件不另存密钥。协作历史默认保存到 `$DSH_HOME/privacy-router/collaboration`（未设置时为 `~/.dsh/privacy-router/collaboration`），使用仅当前用户可访问的目录和文件；也可由主机配置 `stateRoot`，设置页不能修改它。`sandboxBackend`、`dockerPath`、`dockerSocket`、`dockerImage` 和 `pythonPath` 同样仅由主机配置管理；Docker 模式强制使用本机 Unix socket、预先下载的镜像和禁联网容器，不使用远程 Docker context。

## 开发与验证

源码为直接运行的 JavaScript，浏览器部分使用 DSH 提供的 React 和模块加载器，无需安装时构建。

```sh
npm test
npm run pack:check
dsh plugin --profile web add /absolute/path/to/pub-dsh-privacy-router
```

测试覆盖普通模型直连、五档推理、设置更新、逐条消息授权、独立历史、重启重试、授权撤销、私密委托、集成回执、文件冲突和真实命令隔离。

路由模式的隐私分类依赖规则与本地模型，不能保证识别所有敏感内容。协作模式以明确的文件和消息授权为主要边界，并对凭证格式和敏感词增加检查；规则检查不能代替正确划分公开范围。该边界只适用于选择「智能路由」的模型请求，不接管其他插件自行发送的网络请求。
